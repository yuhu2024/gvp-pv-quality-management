# 君合盟药物警戒培训管理系统

行业专家与 IT 专家合力打造的数字化培训平台，以"质量合规专家"为管理理念，助力企业提升药物警戒培训管理水平，满足行业监管要求。

---

## 快速启动（本地开发）

### 前置要求

- Python 3.10+
- pip（Python 包管理器）

### 1. 安装依赖

```bash
cd training_system
pip install -r requirements.txt
```

### 2. 初始化数据库

```bash
python manage.py migrate
```

### 3. 创建初始数据（部门、角色、管理员账号）

```bash
python scripts/init_data.py
```

### 4. 启动开发服务器

```bash
python manage.py runserver 0.0.0.0:8000
```

### 5. 访问系统

- 地址：http://localhost:8000
- 管理员账号：admin / admin123
- 培训管理员：trainer / trainer123
- 学员账号：trainee001 / Abc@12345（需先执行批量创建）

## 功能模块

### 1. 用户与账号管理
- 用户列表：查看所有用户，支持按部门/角色/关键词/状态筛选
- 创建用户：单个创建用户，指定部门、角色、权限
- 批量导入：Excel 文件批量导入用户（支持更新已有用户）
- 个人资料：编辑个人信息、头像、联系方式
- 角色权限：管理员/培训管理员/学员三级角色，模块级权限控制
- 密码管理：修改密码、密码重置、强制改密

### 2. 课程与资料管理
- 课程列表：查看所有课程，支持分类筛选和搜索
- 创建课程：创建新课程，支持多级分类
- 课程审核：创建→待审核→通过/拒绝→发布 工作流
- 资料管理：上传 PPT、Word、PDF、视频等资料（50MB限制）
- 在线预览：PPT 转图片预览、Word/PDF 在线查看、视频在线播放
- 资料审核：资料发布前需管理员审核
- 视频进度：记录观看进度，防作弊（跳跃限制+阈值检测）
- 课程签到：课程学习完成确认，含电子签名
- 自动生成 PPT：基于课程内容自动生成 PPT 课件

### 3. 在线考试
- 考试列表：查看所有考试，显示用户最好成绩
- 创建考试：创建考试并添加题目，支持试卷文件上传
- 题型支持：单选、多选、判断、填空、简答
- 参加考试：在线答题，自动倒计时，超时自动提交
- 自动评分：单选/多选/判断/填空自动评分
- 手动评分：简答题需手动评分，支持 AI 辅助批改
- 成绩管理：查看考试成绩、及格情况、签名信息
- 电子签名：考试确认时需手写签名
- 答题留痕：记录每次答案变更，支持审计追溯
- 自动出卷：基于模板和规则从题库自动组卷
- 考试重考：支持配置重考次数和通过要求

### 4. 题库管理
- 题库列表：按类型/难度/知识点/标签多维度筛选
- 题目管理：创建、编辑、删除题目（5种题型）
- 知识点管理：树形结构的知识点分类
- 批量导入导出：Excel 批量导入/导出题库
- 题目统计：按类型/难度/知识点分布统计

### 5. 培训计划与任务分配
- 计划列表：查看所有培训计划
- 创建计划：创建培训计划，关联课程和考试
- 任务分配：选择任务并批量分配给用户
- 强制培训：设置强制培训人员名单，按部门批量添加
- 状态跟踪：未开始→学习中→待考试→已通过/未通过/已逾期
- 我的任务：学员查看自己的待完成培训任务
- 完成任务：学员标记任务完成，自动记录完成时间和用时

### 6. 学习痕迹记录
- 学习记录：记录登录/登出、查看课程、下载资料、参加考试等行为
- 操作日志：记录管理员的创建/更新/删除/导入/分配等操作
- 用户统计：查看指定用户的培训完成情况汇总
- 管理员仪表盘：系统总览统计（用户数、课程数、考试数、计划数）
- 数据导出：导出学习记录、考试成绩、培训报告为 Excel

### 7. 系统配置
- 系统配置：按分组管理 key-value 配置项
- 成绩权重：配置视频/资料/考试三项成绩权重（总和=100%）
- 时间管理（隐藏功能）：系统时间偏移管理，用于测试场景模拟

### 8. 培训矩阵
- 矩阵管理：按部门定义培训矩阵，设置岗位-课程要求
- 条目配置：课程、岗位、必修/选修、要求周期、优先级
- 分配矩阵：将矩阵分配给部门内所有用户
- 进度同步：从课程学习进度自动同步矩阵完成进度
- 个人视图：用户查看个人培训矩阵，了解岗位培训要求

### 9. 学习排行榜
- 学习时长榜：按学习时长排名，TOP50
- 考试成绩榜：按平均分排名，TOP50
- 课程完成榜：按完成课程数排名，TOP50
- 支持按部门/时间周期筛选

### 10. 证书管理
- 证书模板：创建证书模板，支持占位符渲染
- 证书颁发：选择模板+课程+用户，自动生成 UUID 证书编号
- 证书下载：HTML 打印版证书
- 证书撤销：支持撤销已颁发证书

### 11. 电子签名
- 手写签名：基于 Canvas 的 HTML5 手写签名板
- 签名类型：考试签名和培训签到签名
- 二维码签到：生成签到二维码，扫码后手写签名确认
- 手机端签到：微信扫码后手机端手写签名，自动标记课程完成
- 签名审计：记录签名时间、IP 地址、设备信息

### 12. 大模型 AI 功能
- 模型配置：支持 Kimi/豆包/千问/OpenAI/自定义 5种服务商
- AI 出题：根据课程内容自动生成题目（5种题型）
- AI 批改：自动批改简答题，含评分和评语
- AI 摘要：自动生成课程摘要
- 调用日志：全量记录 AI 调用日志，含 Token 用量和耗时

## 批量创建用户

### 方式一：脚本批量生成

```bash
python scripts/batch_create_users.py --count 300 --prefix trainee --department 技术部 --role 学员
```

参数说明：
- `--count`：创建数量（默认300）
- `--prefix`：用户名前缀（默认 trainee）
- `--department`：部门名称（需先创建部门）
- `--role`：角色（管理员/培训管理员/学员，默认学员）

生成的账号格式：
- 用户名：trainee001, trainee002, ... trainee300
- 默认密码：Abc@12345

### 方式二：Excel 批量导入

1. 下载模板：`templates_import/user_import_template.xlsx`
2. 按照模板格式填写用户信息
3. 通过管理后台"用户管理 → 批量导入"上传Excel文件
4. 或使用命令行：

```bash
python scripts/import_users_excel.py --file your_users.xlsx --skip-existing
```

## 技术栈

- 后端：Python 3.10 + Django 4.2
- 数据库：SQLite（本地开发，开箱即用）
- 前端：Bootstrap 5 + Bootstrap Icons
- 文件处理：openpyxl（Excel）、Pillow（图片处理）
- 二维码：qrcode（签到二维码生成）
- 合规标准：GAMP5 Category 4、21 CFR Part 11、ALCOA+
