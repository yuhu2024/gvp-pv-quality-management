# 君合盟药物警戒培训管理系统 · 界面优化设计方案

> 目标：以世界500强企业标准重塑培训系统界面体验，使其符合医药行业专业、严谨、可信赖的品牌形象。

---

## 1. 设计原则

1. **专业优先** — 医药行业培训系统，视觉语言必须传递严谨与可信赖感
2. **信息清晰** — 降低认知负荷，用户能快速定位核心信息和操作
3. **精致细腻** — 间距、色彩、微动效的细节构成整体品质感
4. **一致性** — 建立统一的设计系统，所有页面遵循相同规范
5. **渐进改良** — 基于现有 Django 模板系统改造，不引入新框架

## 3. 排版系统

### 3.1 字体栈

```css
font-family: 'Inter', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif;
```

- 英文数字：`Inter` — 几何感强，适合数据展示
- 中文：`Noto Sans SC` — 清晰现代，与 Inter 风格协调
- 回退：系统字体栈

## 4. 间距系统

基于 8px 栅格：`4px → 8px → 12px → 16px → 20px → 24px → 32px → 40px → 48px`

| Token | 值 | 场景 |
|-------|-----|------|
| `--space-1` | 4px | 微型间距 |
| `--space-2` | 8px | 图标与文字间距 |
| `--space-3` | 12px | 表单元素间距 |
| `--space-4` | 16px | 卡片内边距、网格间距 |
| `--space-5` | 20px | 卡片头边距 |
| `--space-6` | 24px | 区块间距 |
| `--space-8` | 32px | 大区块间距 |

## 7. 动画与交互

### 7.1 过渡曲线

- 默认：`cubic-bezier(0.4, 0, 0.2, 1)` — 标准缓动
- 进入：`ease-out` — 页面元素出现
- 退出：`ease-in` — 元素消失

### 7.2 持续时间

| 场景 | 时长 | 说明 |
|------|------|------|
| 悬浮态 | 150ms | 按钮、链接、卡片悬浮 |
| 卡片进入 | 300ms | 卡片加载动画 |
| 页面切换 | 200ms | 淡入淡出 |
| 消息提示 | 5s 后自动关闭 | 消息提示 |

### 7.3 尊重用户偏好

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
  }
}
```
