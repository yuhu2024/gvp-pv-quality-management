# 性能确认 (Performance Qualification)

**文档编号：** VAL-PQ-001  
**版本：** 1.0  
**生效日期：** 2026-07-21  

---

## 1. 目的

确认 君合盟药物警戒君合盟药物警戒培训管理系统 (PV Training Management System) 在实际业务负载下能够持续满足性能需求，验证系统的稳定性、并发处理能力和资源使用效率。

| 项目 | 配置 |
|------|------|
| 服务器 | 4核 CPU / 8GB RAM / 100GB SSD |
| 操作系统 | Ubuntu 22.04 LTS |
| 数据库 | PostgreSQL 15 |
| Web 服务器 | Nginx 1.25 |
| 应用服务器 | Gunicorn (4 workers) |
| 测试工具 | Apache Bench (ab) / Locust |
