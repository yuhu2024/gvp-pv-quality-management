从 Bootstrap 默认到世界500强

16项关键改进一览

当前版本 · 改进前
−
Bootstrap 默认蓝色主题，缺乏品牌辨识度
−
内容密集，间距系统不统一
−
字体使用系统默认堆栈，无设计感
−
统计卡片使用高饱和度渐变背景
−
表格样式粗放，缺乏精致感
−
导航栏 Bootstrap 默认蓝色，层级扁平
−
缺少微交互动效和状态反馈
−
整体视觉风格未体现医药行业专业性
优化后 · 世界500强标准
+
深海军蓝品牌色系统 — 专业、冷静、可信赖
+
8px 间距系统 — 统一节奏，呼吸感强
+
Inter + Noto Sans SC — 国际感中文排版
+
纯白卡片 + 柔和阴影 — 干净、当代、高级
+
精致表格 — 小字号大写表头，行间距优化
+
深色导航栏 — 品牌色强化，信息架构清晰
+
